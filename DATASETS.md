# Data directory structure

This file documents the directories `configs/paths.yaml` defines (read by
`src/paths.py` as `PATHS.raw`, `PATHS.processed`, etc.). None of these
directories are committed with data — they're populated by following the
root `README.md`'s "Reproduction order" section. This file describes each
directory's *role*; see the README for the exact commands/scripts that
populate it and the exact filenames produced.

| `PATHS.*` key | Path | Contents |
|---|---|---|
| `raw` | `data/raw/` | Source geodata as obtained from each provider, unmodified: Forest Register stand polygons, sub-region boundaries, elevation and soil rasters, forest mask (see README §2 for the full file table). |
| `external` | `data/external/` | Third-party reference geodata that isn't part of the Forest Register export (currently: the national clearcut-polygon shapefile). See `data/external/README.md`. |
| `intermediate` | `data/intermediate/` | Script-generated intermediate tables: the pivoted per-stand Sentinel-2 time-series feature tables (train/val/test, per README §5) and the height/soil zonal-statistics table (README §6). Regenerated by re-running the download/feature scripts — not committed. |
| `processed` | `data/processed/` | The canonical train/val/test split (`final_split.gpkg`, `final_split_clean.gpkg`) produced by `scripts/split.py` and `scripts/rename_classes.py` (README §3). Deterministic given the same source shapefile and `random_state=42`. |
| `reference` | `data/reference/` | Derived reference tables used to filter/validate the main pipeline, e.g. `clearcut_overlap/stands_overlapping_clearcuts_over20pct.csv` (README §4). |
| `models_trained` | `models/trained/` | Trained model artifacts (`.joblib`) saved by experiment scripts. |
| `models_checkpoints` | `models/checkpoints/` | Intermediate/checkpoint model artifacts, where a script saves more than one snapshot. |
| `outputs_tables` | `outputs/tables/` | CSV result tables (metrics, feature importance, grid-search results) — the source for most numbers reported in thesis ch. 4. |
| `outputs_figures` | `outputs/figures/` | Generated plots (confusion matrices, class-distribution charts, the pixel-based species map, etc.). |
| `outputs_analysis` | `outputs/analysis/` | Ad-hoc analysis outputs that don't fit the tables/figures split above. |
| `outputs_predictions` | `outputs/predictions/` | Per-stand / per-pixel model predictions saved for downstream validation (e.g. pixel-map vs. parcel comparison). |
| `outputs_reports` | `outputs/reports/` | Free-form text/markdown reports generated by a script rather than a human. |
| `archive_data` | `archive/data/` | Superseded data snapshots kept only for traceability, not read by any current script. |

None of the above are tracked in git (see `.gitignore`) — every path is
either regenerated by a script in this repo or, for the license-restricted
raw sources, supplied by you per the root README's data-sourcing table.
